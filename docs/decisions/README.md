# Architecture decision records

Architecture decision records (ADRs) keep durable context for choices that affect boundaries, dependencies, formats, or workflows.

Statuses are `Proposed`, `Accepted`, `Superseded`, or `Rejected`. Accepted records are immutable except for spelling or links; a new ADR supersedes an old decision.
